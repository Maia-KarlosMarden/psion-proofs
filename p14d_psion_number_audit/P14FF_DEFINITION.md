# WP-FF: elastic form factors of the proton and neutron against the static hexagon (pre-registration)

Claim confronted: App. L.4.7 / WP-GEO adopted description: p=(0,4,5), n=(0,1,5) are point psions at hexagon vertices with charges Q9. 
Model form factor (no new parameter besides the ring radius a): F_h(q) = sum_i q_i j0(q |x_i - c|), with x_i the vertex positions, c the unweighted centroid of the three psions (as in the radius code), j0 the spherical Bessel function (orientation average of a rotationally invariant J=1/2 state). F_p(0)=1, F_n(0)=0.
Scale: a is fixed ONLY by the proton slope: <r2>_p = -6 dF_p/dq^2 = 0.8414^2 fm^2 (the same input as the radius audit). The neutron slope is then the parameter-free prediction already found (R_n=-0.154).
Data (shape, not slope): the dipole parametrisation G_D(Q^2)=(1+Q^2/0.71 GeV^2)^-2 for G_E^p (measured to follow it within ~10-15% up to Q^2 ~ 1 GeV^2; to be checked against a source) and the Galster form G_E^n(Q^2) = -mu_n tau/(1+5.6 tau) G_D, tau=Q^2/(4 m_N^2), mu_n=-1.913 (parametrisation of measured data; to be checked).
Comparison points Q^2 = 0.1, 0.2, 0.3, 0.5, 0.8, 1.0 GeV^2 (hbar c = 0.19733 GeV fm).
Criterion: proton: |F_p/G_D - 1| <= 0.15 at all six points; neutron: |F_n - G_E^n| <= 0.15 * max|G_E^n| at all six points.
KILL: proton criterion fails at >= 2 points with Q^2 >= 0.5; SUPPORT: all six pass for both. Otherwise inconclusive.
Anticipation (registered before running): FAIL. A three-point structure with a fixed radius cannot follow the monotonic dipole beyond Q^2 ~ 0.3 GeV^2: F_p departs from G_D by more than 15% at Q^2 >= 0.5 and may change sign near 1 GeV^2.
Limits: static ring, no motion, no magnetic part (G_M needs spin), recoil/relativistic corrections ignored (Breit-frame identification), data used as parametrisations.

# WP-DER: can the psion size be derived from the paper? (pre-registration)

What the paper (v86) contains about lengths and masses relevant to a psion size:
 - the psion is massless (a six-point-lattice sampling deficit, K.7 text); the fundamental scale is Lambda_meta = 1.2609e12 GeV (eq. 6);
 - the single-particle energy is |m_k| = |k - 5/2| (H0 = diag|m|, WP-C2 code), in some energy unit;
 - the cascade ladder m(l) = Lambda_meta exp(-l/b_e) with m(8) ~ 610 MeV (nucleon scale), m(9) = 17.62 MeV, m(7) ~ 21.1 GeV;
 - L.4.7(b): a core bound at Lambda_meta is excluded by the proton form factor by 24 orders of magnitude; a massless-fermion confinement correction E = x hbar c / R with x = 2.04 gives an energy per psion of 333-349 MeV; hbar c/a ~ 163 MeV is r_p converted, not a theory energy.
Candidate sizes DERIVED from these (no fitting of sizes; ring radius a from the proton slope as in WP-FF3):
 C1  core at Lambda_meta: r = hbar c / Lambda_meta = 1.6e-28 fm (a point for this purpose; = WP-FF, L = 5.21).
 C2  Compton length at the nucleon rung: r = hbar c / m(8) = 197.327/610 = 0.3235 fm, common to all psions.
 C3  confinement length: r = x hbar c / E with x = 2.04 and E = 341 MeV (mid of 333-349): r = 1.18 fm common (taken as the confinement radius R; the Gaussian rms is set to R/ sqrt(3)? NO: frozen as rms = R/2.04... see below).
     To avoid inventing a conversion, C3 uses the two obvious readings: rms = hbar c / E = 0.579 fm (C3a) and rms = x hbar c / E = 1.18 fm (C3b).
 C4  psion energy |m_k|: r_k = c / |m_k| with ONE free scale c in [0.1, 2.0] fm (the length unit is not derived); label sizes follow from |m_k|: |m_0| = |m_5| = 2.5, |m_1| = |m_4| = 1.5 (and |m_2| = |m_3| = 0.5).
Loss and data: exactly WP-FF3 (L = max(proton shape/0.15, neutron shape/0.15, R_n z-score); viable iff L < 1).
Decision: a candidate is VIABLE (derived size works) iff L < 1; for C4 the best c is reported and the rule is a hypothesis with 1 free scale (not derived). The question 'can the size be derived from the paper' is answered YES only if C1-C3 gives L < 1 with no free scale; otherwise NO, with C4 reported as the best one-parameter rule.
Anticipation (registered before running): C1 5.21 (fail), C2 about 3.6 (fail), C3a about 4.9 (fail), C3b large (>10, fail, since a^2 would be < 0 or R_n out of window), C4 best L between 1.5 and 3.5 (fail at 15%). Overall: NO, the size cannot be derived from the paper; the fitted sizes are a free phenomenological input.
Limits: the list of candidate derivations is mine and is not exhaustive; Gaussian clouds are a choice; nothing here changes the earlier record.

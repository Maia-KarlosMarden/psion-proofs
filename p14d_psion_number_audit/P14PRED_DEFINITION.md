# WP-PRED: registered prediction for the not-yet-measured Sigma+ charge radius (pre-registration, before any data)

Source of the proposal: arXiv:2309.07850 (psi(2S) -> Sigma+ Sigma-bar e+e- at BESIII/STCF). It reports NO measured Sigma+ radius; its numbers (1.02(23) fm BESIII, 0.78(4) fm STCF) are fits to synthetic data generated with a 0.8 fm input. Projected precision: about 0.2 fm at BESIII (O(10^2) events), about 0.04 fm at STCF. Existing hyperon radius: Sigma- 0.78(10) fm (SELEX); theory range for Sigma+ cited there: 0.6-1.0 fm.
Prediction of the static ring (same convention as WP-GEO/WP-KILL, r_p = 0.8414 fm, r = r_p * sqrt(R)):
  hexagon, Sigma+ = (1,3,5): R = 2.077 -> r = 1.21 fm
  hexagon, Sigma+ = (2,3,4): R = 0.077 -> r = 0.23 fm
  octagon (8 sites), Sigma+ = (1,3,5): R = 1.103 -> r = 0.88 fm
Reading rule (frozen): the static-ring description of the Sigma+ is KILLED if a measurement with total uncertainty <= 0.1 fm gives a radius more than 2 sigma from ALL three values; it is SUPPORTED by a given row if within 1 sigma of that row only. With the BESIII precision (0.2 fm) only the (2,3,4) hexagon value can be separated from the 0.6-1.0 fm theory range.
Status: no data exist; nothing is run. Look-elsewhere: the three rows come from geometries already registered.

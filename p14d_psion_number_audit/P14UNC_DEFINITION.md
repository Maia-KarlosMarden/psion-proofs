# WP-UNC: uncertainty principle applied to the static hexagon (pre-registration)

Question (user): a static hexagon puts each psion at a fixed site. A psion localised to a Gaussian cloud of rms radius r (the form-factor model f=exp(-q^2 r^2/6), <r^2>=r^2) has per-axis sigma = r/sqrt(3), minimum per-axis momentum spread hbar/(2 sigma), 3D p_rms = 3 hbar/(2 r), mean |p| = sqrt(8/(3 pi))*... = 0.921 p_rms (Gaussian ground state, 3D Maxwell). For ANY psion mass, E >= |p| (E = sqrt(p^2+m^2)), so the kinetic floor is mass-independent: T_min = sum_i 0.921 * 3 hbar c /(2 r_i) over the three psions of the composite.
Tests (numbers only, nothing fitted):
 U1. Floor T_min for p=(0,4,5) and n=(0,1,5) using the sizes of (a) WP-FF3 floor r(0,1,4,5)=0.41,0.44,0.69,0.34 fm and (b) WP-JNT2 R1 sizes 0.762,0.73,1.021,0.573 fm. Compare with M_p=938.3, M_n=939.6 MeV. Required net binding B = M - T_min (would be negative if T_min > M).
 U2. Equal-size threshold: smallest common r for which T_min <= M_p; compare with the bound r <~ 0.17 fm from the neutron radius (WP-FF3).
 U3. Localisation vs site spacing: ratio a/sigma (sites resolved if >~ 3) with a from the fits (FF3 a=0.94 fm).
 U4. Point psions (r->0): T_min -> infinity (the static point hexagon violates Delta x Delta p).
Decision rule: the static extended-psion hexagon is "uncertainty-consistent" iff T_min <= M for both nucleons (otherwise a binding energy of size |M - T_min| must be supplied by the dynamics, which the paper does not provide: the stated binding scale is hbar c/a ~ 163 MeV).
Anticipation (before computing): T_min exceeds M_p by a factor 1.5-3 for the FF3 sizes (inconsistent), and is below M only for sizes >~ 0.85 fm; U3 ratio ~ 3-5 (sites resolved).
Limits: Gaussian ground-state bound is the minimum for the assumed density, not for arbitrary shapes (non-Gaussian shapes with the same rms can have larger or comparable <|p|>; the Gaussian is the minimiser of <p^2> at fixed <r^2> only); confinement/binding is not included; psion masses not needed.

# WP-SMS: independent observable Sigma^- minus Sigma^0 (pre-registration)

Frozen optima: O1,O2,O3 of WP-OOS (parameters unchanged). Directions: the V0-approved directions of WP-OOS
(same V0 criterion, scale q>=0.336, DIRS from HYB3 table). Mass scale u=176.1/D as in WP-OOS.
Observable (not used in any fit, nor in OOS): dM = m(Sigma^-) - m(Sigma^0) from the model, observed 4.8 MeV.
Model has no electromagnetic isospin-breaking beyond Coulomb term B and no spin; resolution of the model is
~tens of MeV, so the test is a COARSE window, not a precision test.
Criterion (P-C): 0 <= dM <= 50 MeV (sign right and within ~10x observed).
Success: O3 (the only optimum that passed P-A and P-B) has P-C in a majority of its V0 directions AND the fraction
exceeds the chance baseline by factor >=2, baseline = fraction of (point,direction) V0 pairs satisfying P-C over
1500 random points drawn as in WP-OOS (seed 53).
Anticipation (registered before running): FAILS. O3 passes P-C in some directions but the fraction is not above
2x baseline (p0 >= 0.2), i.e. the observable is not discriminating.
Look-elsewhere: this is test ~#28 of the series; not corrected.

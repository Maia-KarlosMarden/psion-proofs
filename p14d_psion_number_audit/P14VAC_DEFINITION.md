# WP-VAC: do eq.(1) and the K.10 vacua give a circle or six discrete vacua? (pre-registration)

Context: Sec. 13 states U(1)_M exact in eq.(1) (WP-C2, Part 1: U H_k U+ = H_0 for the six phases); K.10 treats six discrete vacua with wall gap m_Z6 and a bias kappa_CP.
Hamiltonian: the WP-C2 one, H(theta,delta) = diag|m| + O_JS + (1/6)(e^{i theta} X + h.c.) + delta*Bond (Fock space of 64 states, same code and normalisations as P14C2_test.py).
Tests:
 A. Continuous phase: E0(theta) at delta=0 for 96 values of theta in [0,2pi): spread max-min (circle if < 1e-10).
 B. The K.10 bias: E0 at the six phases theta_k=2 pi k/6 (delta=0) against DeltaC(s)={0,15,24,27,24,15} computed from m_J(k)=k-5/2 (DeltaC(s)=C(0)-sum_k m(k)m(k+s)).
 C. What explicit breaking can give Z6? E0(theta) at delta in {0.02,0.05,0.1}: Fourier harmonics a_n = |FFT|/96 of E0(theta) for n=1..6 (Bond carries Delta M=1; the only explicit breaking in the code).
Criteria / reporting: A flat -> a degenerate circle (massless Goldstone for the phase, no discrete walls). B: if E0 is equal across k while DeltaC != 0, the K.10 bias is NOT generated by H (an additional input). C: dominant harmonic and a_6/a_1: if a_6/a_1 < 1e-3, the Bond cannot produce six equal minima.
Anticipation (registered before running): A spread < 1e-12; B E0 equal across k to < 1e-12 while DeltaC takes values 0..27; C dominant harmonic n=1 (a_1 ~ delta^2), a_6/a_1 < 1e-3 at all three delta. i.e. the tension is real: eq.(1) plus the registered explicit breaking cannot give Z6 vacua with a gap.
Limits: finite 6-label Fock model, not a field theory; no spatial gradients (a Goldstone mass cannot be measured, only the absence of a potential); delta*Bond is the only breaking tried.
